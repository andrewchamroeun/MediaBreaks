What Are Media Queries?

CSS media queries allow a webpage to change its layout based on the available screen space. This helps content remain readable and usable on phones, tablets, and computers.

Mobile

On smaller screens, content is arranged in one column to make reading easier.

Tablet

When more space becomes available, content can be arranged in multiple columns.

Desktop

Wider screens allow comfortable spacing and a centered page layout.
